# OWL

OWL — проект переносимых инструкций (Agent Skills), справочных материалов, Markdown-шаблонов и текстовой конфигурации для разработки с AI-агентами. Первая целевая среда — OpenCode; общие материалы не должны зависеть от неё или от конкретного проекта. В OWL нет собственных скриптов, CLI, сервера или исполнителя workflow.

Сейчас в репозитории подготовлены тексты семи скилов, три схемы сценариев и несколько шаблонов. Это материалы для дальнейшей сборки и проверки MVP, а не подтверждение их работы в целевом проекте. Инструкция установки `owl-init`, пользовательские входы (`/owl-brief`, `/owl`, `/owl-fix`), конфигурация OpenCode и профили моделей ещё отсутствуют. Способ установки агентом пока не подготовлен; установка, загрузка скилов и сквозная интеграция в целевом проекте не проверены.

Три схемы сценариев: [постановка требований (`brief`)](workflows/brief.md), [выполнение задачи (`develop`)](workflows/develop.md) и [диагностика (`fix`)](workflows/fix.md). Они описывают шаги для агента, но не исполняются отдельной программой. Скилы `owl-document`, `owl-brief`, `owl-fix`, `owl-init` и `owl-self-review` ещё не подготовлены; проверка всего MVP предусмотрена [критериями готовности](docs/owl_spec.md#13-критерии-готовности-mvp).

Локальная очередь — `.owl/tasks/ROADMAP.md` основного дерева (`.owl/tasks/` и `.owl/worktree/` игнорируются Git и должны сохраняться отдельно при переносе работы; `.owl/workflows/` может отслеживаться). Новые деревья задач создаются в `.owl/worktree/<ID>/`; прежние зарегистрированные деревья остаются по фактическим путям Git. Перед работой в отдельном worktree проверьте, что исходная ревизия содержит необходимые документы и правила.
