# OWL

OWL — проект переносимых инструкций (Agent Skills), справочных материалов, Markdown-шаблонов и текстовой конфигурации для разработки с AI-агентами. Первая целевая среда — OpenCode; общие материалы не должны зависеть от неё или от конкретного проекта. В OWL нет собственных скриптов, CLI, сервера или исполнителя workflow.

Сейчас подготовлены основа репозитория, контракт выбора правил, минимальный профиль OKF и текст инструкций `owl-okf` и `owl-tasks`. Загрузка скилов в целевом проекте, установка, пользовательские команды (в том числе `/owl`) и интеграция ещё не проверены.

- [Навигация по документации](docs/index.md) и [правилам разработки OWL](rules/index.md).

- [Контракт выбора правил и передачи контекста](references/rule_selection.md) — справочный порядок для будущих шагов.

- [Инструкция `owl-tasks`](skills/owl-tasks/SKILL.md) — учёт локальных задач и [минимальная постановка](skills/owl-tasks/assets/task.md); применение в целевом проекте не проверено.

Локальная очередь — `tasks/ROADMAP.md` (папка `tasks/` игнорируется Git и должна сохраняться отдельно при переносе работы). Перед работой в отдельном worktree проверьте, что исходная ревизия содержит необходимые документы и правила.
