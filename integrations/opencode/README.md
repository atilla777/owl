# Подключение OWL к OpenCode

Проверяемая версия: OpenCode 1.18.33. [Конфигурация](opencode.json) — **образец для объединения**, а не файл, автоматически применяемый установкой. `owl-init` переносит скилы в `.agents/skills/` проекта; после установки подключите три записи `agent` из образца к проектному `opencode.json` только после осмотра существующей конфигурации и разрешения конфликтов. Не заменяйте файл целиком. В новом файле сохраните `$schema`. Образец не добавляет разрешения или ключи провайдера: они определяются политикой целевого проекта. Перезапустите OpenCode после изменения конфигурации или скилов.

`owl-advanced` — основной профиль Sol 6; выбирайте его в интерфейсе или через `opencode run --agent owl-advanced`. `owl-standard` — профиль Luna 6 для определённой реализации и документов (напрямую или в субагенте); `owl-review` — отдельный субагент Sol 6 для ревью. `default_agent` не устанавливается, поэтому основной профиль нужно выбрать явно. При делегировании передавайте абсолютные пути к рабочему дереву, **общей** `.owl/tasks/ROADMAP.md` основного дерева и папке задачи, ID, первоисточники правил и требований, состояние изменения, проверки, вопросы и следующий шаг. Получатель читает источники сам. Схема сценария задаёт уровень шага, но скил не переключает модель: выбирайте профиль вручную и сверяйте его через `opencode debug agent <имя>`. Если профиль или модель недоступны, остановите соответствующий шаг; не подменяйте уровень.

В целевом проекте проверьте `opencode --version`, `opencode models openai`, `opencode debug agent owl-advanced`, `opencode debug agent owl-standard`, `opencode debug agent owl-review`, `opencode debug skill` (в основном дереве и в worktree). Список моделей подтверждает ID, но не доступ к провайдеру: нужен успешный короткий запрос каждым уровнем в разрешённой среде. Проверьте маршрут `AGENTS.md → rules/index.md → применимые правила` в каждом дереве. Папка `.owl/tasks/` отсутствует в отдельном worktree: путь берите из основного дерева и проверяйте чтение с учётом `external_directory` и иных действующих разрешений. В неинтерактивном `opencode run` запрос разрешения может быть отклонён автоматически. Если чтение требует согласования, запросите доступ по политике проекта в интерактивной сессии; при отказе остановитесь. Не открывайте доступ всем внешним каталогам ради очереди.

Образец не устанавливает пользовательские команды; их проверка относится к следующей задаче. Наличие файлов само по себе не подтверждает выполнение сценария: проверяйте шаги, полномочия и результат отдельно.
