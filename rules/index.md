# Проверка результата

- [Проверки OWL](verification.md) — проверка материалов и достоверности отчёта; читать при планировании проверок, проверке изменений и оценке результатов (включая ревью).

Этот индекс — единая карта выбора правил для MVP. Выбирайте документы по характеру шага и области изменений, не по одному лишь имени файла; тематические теги при их появлении не заменяют индекс. При расширении задачи пересмотрите набор правил, при делегировании передайте ссылки и обеспечьте чтение первоисточников. При добавлении правила обновите индекс. Общий распространяемый справочник для скилов будет разработан отдельно.
